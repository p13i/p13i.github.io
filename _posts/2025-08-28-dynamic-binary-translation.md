QEMU is an open-source program that allows software built
for any computer architecture to run on any other supported
architecture.

UTM is an [open-source](https://github.com/utmapp/UTM)
[app](https://getutm.app/) for all platforms that can
effectively virtualize any operating system on any host.
Yes, macOS can finally run virtually on Windows without any
[hacky](https://hackintosh.com/) and
[unstable](https://www.drweb.com/pravda/issue/?number=1276)
approaches.
